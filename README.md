# Ice Cream Backrooms Mini Demo

Static Three.js mini-game for GitHub Pages.

## Publish on GitHub Pages

1. Upload this folder to a GitHub repository.
2. Open repository settings.
3. Go to Pages.
4. Choose `Deploy from a branch`.
5. Select `main` and `/root`.
6. Open the generated GitHub Pages URL.

No build step is required. Keep `index.html`, `src`, `public`, `vendor`, and `utils` in the repository root.

## Controls

Desktop: WASD or arrow keys to move, drag the right side of the screen to look.

Mobile: left touch stick to move, right side swipe to rotate the camera.
